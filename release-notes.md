## WeaMachine 2.3.1

Windows 64-bit release of **WeaMachine**.

### System Requirements

| Component | Minimum |
|---|---|
| Operating System | Windows 7 / 10 / 11 (64-bit) |
| Processor | x86-64 compatible CPU |
| RAM | 1 GB |
| Storage | 250 MB |
| Architecture | x86-64 |

### Downloads

- **WeaMachine-windows-64.exe** — Windows 64-bit installer
- **WeaMachine-Settings.zip** — Settings and configuration package

### Installation

1. Download the Windows installer.
2. Run `WeaMachine-windows-64.exe`.
3. Complete the installation wizard.
4. Launch WeaMachine from the Start Menu or Desktop shortcut.

### Configuration

`WeaMachine-Settings.zip` contains the settings/configuration package and can be used when transferring or restoring a WeaMachine configuration.

**Version:** `2.3.1`
